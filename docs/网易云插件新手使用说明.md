# Spectrum Terrain 网易云插件新手使用说明

Spectrum Terrain 会把网易云经典播放页左侧变成立体专辑封面和实时频谱。播放音乐时，发光曲线随声音变化，后方曲面留下最近 2.5 秒的频谱历史，配色随专辑封面自动变化。

本说明对应插件 **0.3.1**。当前适配 Windows 64 位、网易云音乐 **3.1.43.205627** 和 BetterNCM **1.3.4**。其他客户端版本的适配情况需要另行确认。

**1. 第一次安装**

已经能打开 BetterNCM 插件管理器的用户，可以直接从第 4 步开始。

1. 从系统托盘退出网易云音乐。托盘在 Windows 任务栏右下角，右键网易云图标后选择退出。
2. 下载 BetterNCM 1.3.4 的 64 位文件 `BetterNCMII.dll`，将它复制到网易云安装目录，并把副本改名为 `msimg32.dll`。它应当与 `cloudmusic.exe` 放在同一层。例如网易云安装在 `D:\CloudMusic`，加载器就放在 `D:\CloudMusic\msimg32.dll`。[BetterNCM 下载页](https://github.com/std-microblock/chromatic/releases/tag/1.3.4)
3. 打开网易云，点击右上角的 BetterNCM 图标。能打开插件管理器，说明加载器已经生效。上述手动安装方法也可以在项目文档中查阅。[BetterNCM 使用说明](https://github.com/std-microblock/chromatic/wiki/使用说明)
4. 在插件管理器中点击「Open Folder」，找到 BetterNCM 的数据目录，再打开其中的 `plugins` 文件夹。有些电脑的数据目录是 `C:\betterncm`，以「Open Folder」实际打开的位置为准。[BetterNCM 目录说明](https://github.com/std-microblock/chromatic/wiki/开发文档)
5. 再次从托盘退出网易云，将 `SpectrumTerrain-0.3.1.plugin` 整个文件复制到 `plugins` 中，保留文件的 `.plugin` 扩展名。
6. 重开网易云，在插件管理器中确认出现 `SpectrumTerrain`，版本为 `0.3.1`。

例如，安装后两个文件可能分别在以下位置。

```text
D:\CloudMusic\msimg32.dll
C:\betterncm\plugins\SpectrumTerrain-0.3.1.plugin
```

**2. 开始使用**

1. 在网易云中播放一首歌。
2. 点击左下角的歌曲封面，展开经典播放页。
3. 左侧会出现立体封面和频谱。切歌后，封面及频谱配色会自动更新。
4. 点击场景左下角的「频谱设置」。面板显示「网易云实时音频」，表示已经收到客户端音频。

播放页打开后会自动连接网易云当前播放的声音。歌曲暂停或暂时没有音频时，面板会显示「等待播放音频」，历史曲面随后逐渐退到零强度。

横轴从低频排到高频，单位为 Hz 或 kHz。曲面高度表示相对强度，纵深表示最近 2.5 秒的历史。高度上的百分比用于观察声音变化。

**3. 调整视角和效果**

在三维场景上按住鼠标左键拖动，可以改变观察角度。滚轮可以放大或缩小。调乱视角时，展开「频谱设置」并点击「复位视角」。

点击「自动绕转」可以让视角缓慢变化，再点一次即可关闭。自动绕转初始关闭，要调整绕转快慢，使用「绕转速度」滑块。

| 控件 | 调节后的变化 | 初始默认值 |
| --- | --- | --- |
| 显示坐标轴 | 显示或隐藏网格及坐标标签 | 开 |
| 曲面不透明度 | 越高，曲面越实、越明显 | 70% |
| 后方保留亮度 | 越高，较早的历史曲面越清楚 | 51% |
| 光晕强度 | 越高，前沿发光越明显 | 50% |
| 光晕半径 | 越大，亮线周围的光晕越宽 | 12 px |
| 强度增益 | 越高，曲面起伏越大 | 115% |
| 频率平滑 | 越高，相邻频段之间越平缓 | 50% |
| 绕转速度 | 控制自动绕转时的速度 | 10 °/s |
| 冻结频谱 | 固定当前波形，便于观察和调参 | 关 |

效果滑块的数值会保存在本机，下次打开播放页时继续使用。点击「恢复默认效果」会重置效果滑块和坐标轴开关。要继续更新波形，单独取消勾选「冻结频谱」。视角使用「复位视角」恢复。

面板右上角的 FPS 表示当前绘制帧率。打开面板后稍等片刻，数值就会出现。实际帧率与电脑、窗口大小和同时运行的程序有关。

**4. 升级与恢复原播放页**

升级时先从托盘退出网易云，将 `plugins` 中旧版本的 `SpectrumTerrain-*.plugin` 移到别处，再放入新版本，最后重开网易云。该文件夹里只保留一个版本的 SpectrumTerrain。

要恢复网易云原播放页，同样先退出网易云，再把 SpectrumTerrain 的 `.plugin` 文件从 `plugins` 移出，重新启动即可。`msimg32.dll` 用于加载 BetterNCM，保留它可以继续使用其他 BetterNCM 插件。

**5. 常见问题**

| 遇到的情况 | 操作方法 |
| --- | --- |
| 插件管理器里找不到 SpectrumTerrain | 用「Open Folder」重新确认目录，检查文件在 `plugins` 中，文件扩展名为 `.plugin`，然后从托盘退出并重开网易云 |
| 装好后还是原来的封面 | 展开歌曲的经典播放页，确认插件版本为 0.3.1，再尝试收起并重新展开 |
| 仍然出现演示选项 | 检查 `plugins` 中是否保留了 0.1.0 或 0.2.0 的旧包，按升级步骤换成 0.3.1 |
| 有声音，波形却固定着 | 打开「频谱设置」，取消勾选「冻结频谱」 |
| 显示「等待播放音频」 | 确认网易云正在播放，等待短暂缓冲。持续无响应时，收起并重新展开播放页 |
| 显示「客户端音频不可用」 | 收起并重新展开播放页，或重启网易云。若刚更新过网易云，核对客户端版本 |
| 封面先模糊后变清楚 | 高清封面正在加载。加载失败时会继续使用客户端已有图片 |
| 视角太偏、画面太小 | 点击「复位视角」，再按需要用滚轮缩放 |
| 参数调得不满意 | 点击「恢复默认效果」 |
| 安装加载器后网易云无法启动 | 退出网易云，将本次复制进网易云安装目录的 `msimg32.dll` 移出后重试 |

**6. 从源码生成插件包**

拿到现成插件包的用户可以直接按前面的步骤安装。从仓库构建时，使用 Windows、Node.js 22 或更高版本，以及系统自带的 `tar.exe`。源码位于 `main` 分支的 `src/netease` 文件夹。

```powershell
git clone --branch main https://github.com/Vort333X/Spectrum_Terrain.git
cd Spectrum_Terrain
npm ci
npm run build:netease
```

构建完成后，生成的插件包位于仓库的 `dist-netease` 文件夹中。
