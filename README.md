# Spectrum Terrain · 频谱地形

实时三维频谱瀑布图，提供网页与 Wallpaper Engine 壁纸、立体播放页原型和网易云音乐插件。横向从低频排到高频，曲面高度表示相对强度，纵深显示最近 2.5 秒。最前沿的发光线显示当前频谱，可以拖动旋转和滚轮缩放。

当前版本 **0.3.6**，采用 **MIT** 许可证。

[插件安装与使用](docs/网易云插件新手使用说明.md) · [版本记录](CHANGELOG.md) · [参与贡献](CONTRIBUTING.md) · [许可证](LICENSE) · [第三方组件](THIRD_PARTY_NOTICES.md)

网页端提供系统音频监听、九套渐变配色和效果调试。网易云插件自动接入当前歌曲的音频，以立体专辑封面和透明频谱融入经典播放页。

开发环境使用 Node.js 22 或更高版本。网易云插件适配 Windows 64 位，当前验证的客户端组合为网易云音乐 **3.1.43.205627** 与 BetterNCM **1.3.4**。客户端更新后的兼容性需要重新验证。

源码统一放在 `main` 分支，按使用场景分目录。

| 功能 | 源码目录 | 构建命令 | 生成位置 |
| --- | --- | --- | --- |
| 网页与 Wallpaper Engine 壁纸 | `src/web/` | `npm run build` | `dist/index.html` |
| 立体播放页原型 | `src/player/` | `npm run build:player` | `dist-player/index.html` |
| 网易云音乐插件 | `src/netease/` | `npm run build:netease` | `dist-netease/*.plugin` |
| 共用音频分析、封面取色和三维渲染 | `src/shared/` | 随各入口构建 | 打包到各入口 |

各入口共用根目录的依赖，首次使用先运行 `npm ci`。网易云插件的安装与调参见[新手使用说明](docs/网易云插件新手使用说明.md)。

## 浏览器预览

```powershell
git clone https://github.com/Vort333X/Spectrum_Terrain.git
cd Spectrum_Terrain
npm ci
npm run build
```

在 Windows 上用 Chrome 或 Edge 打开 `dist/index.html`。页面先显示无声的演示动画。点击「监听系统音频」，在浏览器弹出的共享选项中选择整个屏幕，勾选「共享系统音频」。只想听某个标签页时，可以选该标签页并共享其音频。点击「停止监听」或在浏览器中结束共享，页面会回到演示。

共享由浏览器管理。页面只将音轨接入本地频谱分析，屏幕画面不会进入渲染器。浏览器是否提供系统音轨取决于共享来源和系统支持。

## 立体播放页原型

在安装依赖后运行 `npm run build:player`，用 Chrome 或 Edge 打开 `dist-player/index.html`。可以切换三首演示曲目，也可以通过「更换封面」载入本地图片。封面底边与频谱的低频侧共用同一条边，拖动旋转或滚轮缩放时，封面和曲面会一起改变视角。宽窗口把场景放大并靠左摆放，窄窗口会按可用宽度重新取景。

切换封面时，程序从封面取主色，为频谱曲面、前沿亮线和播放栏生成深浅配色。近乎黑白的封面使用中性色。演示进度可以拖动，也可以切换到浏览器的系统音频监听。监听期间，播放按钮用于暂停或恢复频谱动画。

## 网易云音乐插件

首次安装、升级和调参可以阅读[网易云插件新手使用说明](docs/网易云插件新手使用说明.md)。

Windows 下使用 Node.js 22 及以上版本和系统自带的 `tar.exe`，运行 `npm run build:netease`，在 `dist-netease` 中生成 `SpectrumTerrain-<版本>.plugin`。

1. 安装 [BetterNCM](https://github.com/std-microblock/chromatic/wiki/使用说明)，确认客户端里能打开插件管理器。
2. 从系统托盘退出网易云，将整个 `.plugin` 文件复制到 BetterNCM 数据目录下的 `plugins` 文件夹。升级时先移出旧版本的 SpectrumTerrain 插件包。可以从插件管理器的「Open Folder」找到数据目录。
3. 重开网易云并展开经典播放页。场景从客户端读取当前封面和主色，通过透明画布叠在网易云背景上。对网易云 CDN 的缩略封面会尝试加载高清版本，离线时沿用客户端已有图片。
4. 播放页打开后自动监听网易云的播放音频。插件按客户端 3.1.43 的 48 kHz、16 位双声道 PCM 分析频谱。收起播放页时释放监听和渲染资源，通过页面变化事件恢复显示。等待音频时曲面回到零强度。
5. 左下角「频谱设置」提供效果参数、实测绘制帧率和可保存的帧率上限（默认 60 FPS，0 为不限帧，最高 240 FPS）。插件保留手动拖动与缩放，移除了自动绕转。插件沿用 60 次/秒频谱更新、255 列曲面和 2.5 秒历史。

插件通过客户端暂停、切歌和跳转事件重置音频分析。音频包短暂延迟时保留分析窗口，卡顿后优先取新的音频。运行 `npm run test:audio` 可检查音频包抖动、积压、播放状态变化和监听释放。

频谱计算优先在 Web Worker 中运行，界面线程接收分析结果后更新画面。暂停、跳转和切歌会丢弃旧结果，收起播放页会终止 Worker。后台线程依次尝试 Blob、Data URL 和 BetterNCM 本机 HTTP 宿主。宿主使用加载器已有的本地文件挂载接口，仅挂载插件的 `worker` 子目录，PCM 和结果通过 MessagePort 直传。所有方式都失败时使用兼容分析，并保留缩短后的失败原因。收起播放页时移除宿主并终止线程。

要恢复原播放页，从托盘退出网易云，将 SpectrumTerrain 插件包从 `plugins` 移出，再打开客户端。

## 效果调试

展开左侧「效果调试」。可以用演示、对数扫频或双频脉冲检查曲面，打开「冻结频谱」后可以固定当前波形再调参数。界面支持显示或隐藏坐标轴、曲面不透明度、后方保留亮度、光晕强度和半径、强度增益、频率平滑和自动绕转速度。效果参数会保存在浏览器中，可通过「恢复默认效果」重置。

浏览器横轴为对数频率，单位是 Hz 或 kHz。纵深从 0 s 向过去延伸，高度为 0–100% 的相对强度。Wallpaper Engine 只提供从低到高排列的频段，壁纸端横轴用频段序号。

## 导入 Wallpaper Engine

构建后，在 Wallpaper Engine 编辑器创建网页壁纸，导入 `dist/index.html`。导入时保留 `dist` 里的配套文件。壁纸全屏显示，自动使用 Wallpaper Engine 提供的系统频谱。

网页和壁纸共用 255 列、151 行的曲面，频率方向用保持峰值范围的三次插值细分，时间方向也做插值。网页用 Web Audio API 把共享音轨划分为 128 个频段，壁纸版把宿主提供的 64 个频段插值到 128 列。渲染会采用屏幕的像素倍率，上限为 2×。浏览器最多每秒读取 60 次频谱，壁纸宿主约每秒提供 30 帧。两个版本都在绘制时插值，并只上传新增的历史行。浏览器左上角显示实测绘制帧率。

### 在壁纸宿主里调参

在 Wallpaper Engine 编辑器中打开「更改项目设置」，可按下表添加对应的用户属性。配置后，在 Wallpaper Engine 的壁纸属性中调整。浏览器调试面板的本地设置保存在浏览器中。

| 属性键 | 类型 | 范围或选项 | 默认值 |
| --- | --- | --- | --- |
| `axes` | 复选框 | 显示坐标轴 | 开 |
| `opacity` | 滑块 | 0–100% | 78 |
| `trail` | 滑块 | 0–100% | 18 |
| `glow` | 滑块 | 0–100% | 55 |
| `radius` | 滑块 | 2–20 px | 8 |
| `gain` | 滑块 | 25–300% | 100 |
| `smoothing` | 滑块 | 0–80% | 50 |
| `orbitspeed` | 滑块 | 0–30 °/s | 9 |
| `palette` | 下拉菜单 | 翡翠绿 `jade`、紫橙 `ember`、银灰 `silver`、深海蓝 `ocean`、极光青 `aurora`、熔岩红 `lava`、琥珀金 `amber`、霓虹粉 `neon`、电光紫 `violet` | `jade` |

## 源码

```text
src/
  web/       网页与壁纸入口、HTML 和样式
  player/    立体播放页原型入口、HTML 和样式
  netease/   网易云插件入口、PCM 分析、客户端接口和插件清单
  shared/    音频频段、Three.js 渲染、频谱历史、封面取色和效果参数
scripts/     各入口的构建脚本
docs/        新手使用说明
```

修改音频处理后可以运行 `npm run test:audio`，检查包抖动、缓冲积压、暂停、切歌、跳转和监听释放。开发与问题反馈方式见[参与贡献](CONTRIBUTING.md)。
