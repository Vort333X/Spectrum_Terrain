# Spectrum Terrain · 频谱地形

实时三维频谱瀑布图。横向从低频排到高频，曲面高度表示相对强度，纵深显示最近 2.5 秒。纯黑背景上的半透明曲面保留频谱历史，最前沿的发光线显示当前频谱。可以拖动旋转、滚轮缩放、自动绕转，或切换翡翠绿、紫橙和银灰配色。

## 浏览器预览

```powershell
npm ci
npm run build
```

在 Windows 上用 Chrome 或 Edge 打开 `dist/index.html`。页面先显示无声的演示动画。点击「监听系统音频」，在浏览器弹出的共享选项中选择整个屏幕，勾选「共享系统音频」。只想听某个标签页时，可以选该标签页并共享其音频。点击「停止监听」或在浏览器中结束共享，页面会回到演示。

共享由浏览器管理。页面只将音轨接入本地频谱分析，屏幕画面不会进入渲染器。浏览器是否提供系统音轨取决于共享来源和系统支持。

## 效果调试

展开左侧「效果调试」。可以用演示、对数扫频或双频脉冲检查曲面，打开「冻结频谱」后可以固定当前波形再调参数。界面支持显示或隐藏坐标轴、曲面不透明度、后方保留亮度、光晕强度和半径、强度增益和自动绕转速度。效果参数会保存在浏览器中，可通过「恢复默认效果」重置。

浏览器横轴为对数频率，单位是 Hz 或 kHz。纵深从 0 s 向过去延伸，高度为 0–100% 的相对强度。Wallpaper Engine 只提供从低到高排列的频段，壁纸端横轴用频段序号。

## 导入 Wallpaper Engine

构建后，在 Wallpaper Engine 编辑器创建网页壁纸，导入 `dist/index.html`。导入时保留 `dist` 里的配套文件。壁纸全屏显示，自动使用 Wallpaper Engine 提供的系统频谱。

网页和壁纸共用 128 列、151 行的曲面，历史采样之间做插值。网页用 Web Audio API 把共享音轨划分为 128 个频段，壁纸版把宿主提供的 64 个频段插值到 128 列。渲染会采用屏幕的像素倍率，上限为 2×。浏览器最多每秒读取 60 次频谱，壁纸宿主约每秒提供 30 帧。两个版本都在绘制时插值，并只上传新增的历史行。浏览器左上角显示实测绘制帧率。

### 在壁纸宿主里调参

在 Wallpaper Engine 编辑器中打开「更改项目设置」，可按下表添加对应的用户属性。配置后，在 Wallpaper Engine 的壁纸属性中调整。浏览器调试面板的本地设置保存在浏览器中。

| 属性键 | 类型 | 范围或选项 | 默认值 |
| --- | --- | --- | --- |
| `axes` | 复选框 | 显示坐标轴 | 开 |
| `opacity` | 滑块 | 0–100% | 78 |
| `trail` | 滑块 | 0–100% | 18 |
| `glow` | 滑块 | 0–100% | 55 |
| `radius` | 滑块 | 2–20 px | 8 |
| `gain` | 滑块 | 25–300% | 100 |
| `orbitspeed` | 滑块 | 0–30 °/s | 9 |
| `palette` | 下拉菜单 | 翡翠绿 `jade`、紫橙 `ember`、银灰 `silver` | `jade` |

## 源码

- `src/audio.ts` 处理系统音频共享、FFT 和演示信号。
- `src/terrain.ts` 负责 Three.js 网格、透明渐变、发光前沿和镜头。
- `src/axes.ts` 负责坐标刻度和标签。
- `src/effects.ts` 负责实时调参和浏览器设置保存。
- `src/main.ts` 处理频谱历史、音频来源和页面交互。
