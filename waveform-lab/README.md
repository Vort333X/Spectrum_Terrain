# 波形样式实验室

这里保留原网页版本的系统音频监听、演示动画和效果调试，作为新波形样式的试验入口。基线是整理时 0.3.6 中的网页地形效果，现提供三种形态与三种显示风格，默认打开离散频率柱。

## 打开页面

在仓库根目录安装依赖并构建：

```powershell
npm ci
npm run build:lab
```

使用 Chrome 或 Edge 打开本目录中的 `dist/index.html`。无需安装网易云插件。源码修改后重新运行构建，再刷新页面。

依赖共用仓库根目录的 `node_modules` 和锁文件，本目录不需要单独安装。运行 `npm run check:lab` 可单独检查试验代码的类型。试验目录有独立的 TypeScript 配置，正式入口的类型检查不包含试验文件。

构建脚本也支持从本目录运行 `node build.mjs`。试验构建保留可读代码和 source map，便于定位绘制问题。

## 测试方法

在「波形样式」中选择形态，切换时保留当前输入、配色、相机和历史，不重新开始监听。

| 形态 | 特点 |
| --- | --- |
| 离散频率柱 | 32、64 或 128 根频段柱，沿纵深显示 36 层历史；前排浅色发光，间隙可调 |
| 连续地形 · 原版 | 连续曲面与前沿发光线，选择「柔光透明」可对比原版 |
| 层叠光带 | 沿历史方向切成 64 层细轮廓，贴合原版曲面，保留线条之间的空隙 |

「显示风格」可选柔光透明、实体渐变或霓虹边缘。柱体的霓虹风格突出前排边框，后方只保留低亮度柱顶轮廓；地形的霓虹风格按高度绘制等高线，去掉纵横网格；光带的霓虹风格主要增强前沿亮线与光晕。强度、后方亮度、不透明度和光晕仍可在「效果调试」中调整。

频率柱最前排使用带配色倾向的浅白色，每根柱顶有独立亮线和光晕，保留柱间断开。光晕强度和半径控制这些柱顶高亮。后方历史柱不加同样的光晕。层叠光带复用原版曲面的起伏，在前景峰值后隐藏被遮挡的线段；前沿发光，后方只绘制固定细线，避免增加层数后光晕叠加。

形态、显示风格、柱数和间隙会单独保存。它们不受「恢复默认效果」影响；该按钮重置下方效果滑块。各形态共用一个渲染器和历史纹理，只有当前形态参与绘制；柱体和光带采用实例化绘制。

页面默认运行演示动画。展开「效果调试」后，可以切换对数扫频、双频脉冲，检查频段响应和样式表现。配色、冻结、坐标轴及效果滑块均可使用。

点击「监听系统音频」，在浏览器共享窗口选择音频来源并勾选共享音频，即可用实际音乐测试。停止共享后恢复演示。页面只分析音轨，屏幕画面不参与绘制。

对比样式时使用相同测试信号、参数、窗口大小和像素倍率，分别观察画面和 FPS。测试过程中切换输入、冻结与恢复，并检查调整视角和窗口大小后的表现。

运行 `npm run test:lab` 可检查频段覆盖、柱体数量与间距、绘制顺序和几何体释放。浏览器中的实际帧率需要在目标电脑上观察。

## 修改位置

```text
waveform-lab/
  build.mjs               本目录的构建脚本
  tsconfig.json           独立类型检查配置
  test.mjs                频段覆盖和资源释放回归检查
  src/
    index.html            网页结构与调试控件
    style.css             页面样式
    main.ts               音频来源、控件绑定和动画循环
    terrain.ts            当前三维地形和发光曲线
    spectrum-styles.ts    实例化频率柱和层叠光带
    display-options.ts    样式选项、默认值和存储校验
    spectrum-history.ts   历史推进与平滑
    axes.ts               坐标轴、网格和标签
    effects.ts            参数绑定与试验页专用存储
    audio.ts              系统音频分析及演示测试信号
    palettes.ts           配色
  dist/                   构建后生成的可打开页面，不提交到 Git
```

绘制、音频、历史和效果代码均是本目录的独立副本，不引用 `src/shared`。试验参数使用 `spectrum-terrain-lab-effects` 和 `spectrum-terrain-lab-display` 保存，与原网页及插件参数分开。

新样式的源码先放在本目录中，完成效果、性能和切换验证后，再选择性接入正式入口。网易云插件仍从 `src/netease` 和 `src/shared` 构建，原网页与 Wallpaper Engine 入口仍为 `src/web`。

本目录源码遵循仓库根目录的 [MIT 许可证](../LICENSE)。
